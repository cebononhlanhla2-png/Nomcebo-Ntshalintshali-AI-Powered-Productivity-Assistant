
# 🤖 AI Productivity Assistant — Gemini 3.5 Flash

A command-line productivity suite that automates common workplace tasks using
Google's **Gemini 3.5 Flash** model. Built for the **AI Skill Accelerator Programme**
project brief.

---

## ✨ Features

| # | Tool | What it does |
|---|------|--------------|
| 1 | 📧 **Smart Email Generator** | Drafts context-aware professional emails with tone and audience control |
| 2 | 📝 **Meeting Notes Summarizer** | Converts raw notes into structured summaries with decisions and action items |
| 3 | 📅 **AI Task Planner** | Builds time-blocked day/week plans using the Eisenhower Matrix |
| 4 | 🔎 **AI Research Assistant** | Summarises topics into insights, implications, and recommendations |
| 5 | 💬 **AI Workplace Chatbot** | Interactive multi-turn assistant with conversation memory |

Every AI output includes a **Responsible AI disclaimer** reminding users to validate results.

---

## 📋 Prerequisites

- **Python 3.10+**
- A **Gemini API key** (free tier available — no credit card required)
